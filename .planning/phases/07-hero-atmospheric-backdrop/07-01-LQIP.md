## Generation command (for reproducibility)

```
node -e "
const sharp = require('/Users/mc/.npm/_npx/76dc10efc80ca823/node_modules/sharp');
sharp('<body>-image.png').resize(24, null, {fit:'inside'}).webp({quality:20}).toFile('/tmp/<body>-lqip.webp')
  .then(info => console.log(info)).catch(e => console.error(e));
"
printf 'data:image/webp;base64,'; base64 -i /tmp/<body>-lqip.webp | tr -d '\n'
```

Tool: npx sharp-cli (Node sharp module, ephemeral via npx — no package.json dependency)
Quality: 20 (WebP), dimensions: 24px wide x 13px tall
