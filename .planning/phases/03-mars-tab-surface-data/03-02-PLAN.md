# useMarsData (from Plan 03-01)

```js
import { useMarsData } from '../hooks/useMarsData.js'

const { data, isLoading, isError, dataUpdatedAt } = useMarsData()
// data is undefined until first successful fetch; afterward:
// data = { sol, terrestrial_date, min_temp, max_temp, pressure, wind_speed, humidity, atmo_opacity }
// isLoading = true ONLY on first mount before any data lands (false during background refetches)
// isError = true if the fetch failed or JSON.parse threw
// dataUpdatedAt = epoch ms of last successful fetch (Date(dataUpdatedAt) is the timestamp prop for LastUpdated)
```

CRITICAL: Use `isLoading`, NOT `isFetching`. `isFetching` is true during hourly background refetches; using it would flash skeletons every hour and violate D-18 (silent background refetch).

When state='loading': renders <LoadingState /> in the value slot, no value/unit/tooltip shown.
When state='error': renders "Data temporarily unavailable" (exact string), no value/unit/tooltip shown.
When state='ok': renders the value (em-dash for null/undefined), optional unit, tooltip wrap when tooltipKey resolves.

# LastUpdated signature (Phase 2 Plan 02 — SHIPPED, DO NOT MODIFY)

```jsx
<LastUpdated

  prefix="Last updated"                // optional; default is "Last updated"

```

When timestamp is 0 (epoch start) — which is what `dataUpdatedAt` is BEFORE the first successful fetch — `new Date(0)` is a valid Date object representing 1970-01-01, and LastUpdated will render "N years ago". To avoid that, pass `dataUpdatedAt ? new Date(dataUpdatedAt) : null` so LastUpdated renders the em-dash glyph during the initial loading state.

// Number formatters — kept inline per D-26 / Claude's discretion. If Phase 4
// needs the same formatters, extract to src/utils/formatters.js then.
function formatInt(value) {
  if (value === null || value === undefined) return null
  const n = Number(value)
  if (Number.isNaN(n)) return null
  return Math.round(n).toString()
}

function formatOneDecimal(value) {
  if (value === null || value === undefined) return null
  const n = Number(value)
  if (Number.isNaN(n)) return null
  return n.toFixed(1)
}

function MarsTab() {
  const { data, isLoading, isError, dataUpdatedAt } = useMarsData()

  // Shared card state — first-mount loading or hard error covers every card.
  // isFetching is intentionally NOT consulted: background refetches stay silent (D-18).
