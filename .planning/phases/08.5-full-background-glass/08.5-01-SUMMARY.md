## What Was Built

**BodyHero.jsx** — outer container changed from `relative w-full aspect-[16/7] rounded-lg overflow-hidden mb-4` to `absolute inset-0 overflow-hidden` with `gridArea: '1 / 1'`. The `<img>` element had its center-crop hack removed (no more `height:200%/top:50%/translateY(-50%)`), replaced with `absolute inset-0 w-full h-full object-cover object-center`. The bottom vignette div was deleted entirely. LQIP base64 strings, NASA honesty label, per-body loaded state, and cross-fade opacity logic are all preserved unchanged.

**useScrollParallax.js** — Added `ticking.current = false` to the cleanup return (F-03 fix). This prevents the ticking flag from staying `true` after a tab-switch cancels an in-flight RAF, which would cause the first scroll event after re-mount to be silently dropped.

**App.jsx** — Replaced the sibling-flow `<BodyHero>` + data panel `<div>` with a CSS Grid wrapper (`gridTemplateColumns:1fr, minHeight:70vh`). The glass panel shares `gridArea:'1/1'` with BodyHero, so both occupy the same grid cell — the panel defines cell height, BodyHero fills it via `absolute inset-0`. Panel classes updated: `backdrop-blur-md bg-slate-950/50 border border-slate-700/40 rounded-xl p-6 md:p-8 m-4 md:m-8 relative z-10`.
