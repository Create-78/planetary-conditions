# /log — Update Session Logs

Capture what happened in this session.

## Instructions

1. Review the work done in this session
2. Add entry to @logs/sessions_log.md:
   - Date
   - Summary (1-2 sentences)
   - Tasks completed
   - Decisions made
   - Files changed
   - Open items
3. Check if insights should go to @logs/learnings_log.md:
   - Patterns that emerged
   - Things that worked well (or didn't)
   - Insights applicable elsewhere

## Session Log Format

```markdown
## Session: [Date]

### Summary
[1-2 sentences]

### Tasks Completed
- [Task]: [Outcome]

### Decisions Made
- [Decision]: [Rationale]

### Files Changed
- `[filepath]`: [What changed]

### Open Items
- [Follow-up needed]

### Notes
[Additional context]
```

## Learnings Format

```markdown
### [Date] — [Title]

**Learning:** [Actionable statement]

**Context:** [What led to this]

**Application:** [How to use elsewhere]

**Tags:** [Categories]
```

## Output

Update both log files and confirm what was captured.
